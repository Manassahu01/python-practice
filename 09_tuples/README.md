Welcome to the **Tuples** section of my **Python Practice** repository.

## 🔑 Important Characteristics of Tuples

### 1. Ordered

Tuples maintain the order of their elements.

```python
numbers = (10, 20, 30, 40)
```

### 2. Immutable

Tuple elements cannot be modified after creation.

```python
numbers = (10, 20, 30)

# This will give an error:
# numbers[0] = 100
```

### 3. Allow Duplicate Values

```python
numbers = (10, 20, 10, 30)
```

### 4. Allow Different Data Types

```python
data = (10, 25.5, "Python", True)
```

## 🔄 List vs Tuple

| Feature | List | Tuple |
|---|---|---|
| Syntax | `[]` | `()` |
| Mutable | Yes | No |
| Ordered | Yes | Yes |
| Duplicates | Yes | Yes |
| Indexing | Yes | Yes |
| Slicing | Yes | Yes |
| Methods | Many | Few |
| Performance | Comparatively slower | Comparatively faster |
