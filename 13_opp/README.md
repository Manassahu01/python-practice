# 13 - Object-Oriented Programming (OOP)

Object-Oriented Programming (OOP) is a programming approach where programs are designed using **classes and objects**.

Python supports OOP and provides features such as **classes, objects, constructors, inheritance, encapsulation, polymorphism, and abstraction**.

This chapter focuses on learning OOP concepts step by step with simple examples and real-life use cases.
